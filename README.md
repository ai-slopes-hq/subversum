# Складка

Одна кнопка, один голос: VCO (с FM) → wavefolder → low pass gate с резонансом. Web Audio, без зависимостей, под телефон.

- Тап играет случайную ноту. Октава всегда 1 или 2, всё остальное случайно: нота, форма волны, FM, фолд, срез, резонанс, затухание.
- Зажатие запускает мелодию в случайном ладу, темп 110–135 BPM, тембр последнего тапа не меняется.
- Один файл `index.html`. Для Vercel Web Analytics в нём есть сниппет, на других хостингах он ничего не делает.
