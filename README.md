# Складка

Одна кнопка, один голос: VCO (с FM) → wavefolder → low pass gate с резонансом. Web Audio, без зависимостей, под телефон.

- Любое нажатие запускает арпеджиатор: случайный патч (форма волны, FM, фолд, срез, резонанс, затухание, LFO), лад, тональность и темп 110–135 BPM. Он играет, пока палец на экране, а быстрый тап ловит один удар.
- Октава всегда 1 или 2.
- Один файл `index.html`. Для Vercel Web Analytics в нём есть сниппет, на других хостингах он ничего не делает.

Подробное описание решения: [DESIGN.md](DESIGN.md).

Страницу можно установить как приложение (PWA): в Chrome через меню браузера, на iPhone через «Поделиться» → «На экран Домой». После установки она работает без сети.

Внешний вид выбирается случайно при каждом запуске из трёх: янтарь, ризограф, осциллограф. Принудительно: `?skin=amber|riso|scope`.
