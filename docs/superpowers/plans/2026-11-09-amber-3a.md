# Amber 3a Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перенести звук мира amber (патч, мелодия, секвенсор, макросы, голос) на Rust-движок с проверкой нативным WAV и минимальным запуском в `/next/`.

**Architecture:** Четыре новых блока (`Biquad`, `Shaper`, `Lfo`, `StepClock`) выходят в `versum-dsp` тегом v0.3.0. Затем в `engine` появляются чистые модули `patch`/`melody`/`macros` (сверяются с legacy по фикстуре), голос `amber` и интеграция мира в `Engine` с телеметрией версии 2.

**Tech Stack:** Rust (workspace `crates/engine`, `crates/wasm`), TS (`web/audio`, `web/app`), vitest, Node для выгрузки фикстур из legacy.

**Spec:** `docs/superpowers/specs/2026-11-09-amber-3a-design.md` (родительская: `2026-11-09-rust-wasm-refactor-design.md`).

## Global Constraints

- Блок `versum-dsp`: `new` аллоцирует, `process`/`tick` без аллокаций, есть `reset`, NaN-guard, звук f32, фазы f64 (§2).
- Частота дискретизации в тестах 48000 Гц; `Block` реализуется как в `src/onepole.rs`.
- Тесты каждого блока включают: «блоком = по сэмплу» побитово (`testkit::assert_blockwise_eq`), ноль аллокаций (`count_allocs`), нет NaN, DC около нуля, пик ≤ 1 (§6).
- `alias_db` осциллятора и фолда не хуже −70 дБ.
- Сид: u32; `roll()` и `makeSeq` дают тот же патч и те же 16 шагов, что legacy; порядок вызовов `rng.next()` повторяет legacy (§1, §3).
- bpm = round(rnd(110,135)); пул MIDI 24..47; 7 ладов; шаг 0 всегда velocity 1; пауза = velocity 0.
- Ворота — вактрол-`Lpg`, режим Combo; фолд — `Shaper` 4× с таблицей `sin(5π·x)`, не ADAA1.
- Версия телеметрии 2; раскладка `Telemetry` в Rust (`const _` assert) и `web/audio/protocol.ts` меняется вместе.
- Skin, ввод, жесты на стороне ввода, шина эффектов, другие миры — вне объёма.
- В git не коммитятся: `[patch]`, `.cargo/config.toml` с локальными путями. Push, тег и force-операции — только после «да» автора.
- Коммиты и PR заканчиваются строками атрибуции из системного напоминания сессии.

## Review Focus

- Сид 0 и значения > 2²⁴ (например 4294967295): патч и мелодия те же, что в legacy; Seed не теряет биты на пути UI → worklet → wasm.
- `Tempo` посреди такта и `Hold` на границе шага: шаги не дублируются и не теряются, фаза сохраняется.
- Быстрая серия нот (P-тап подряд, шаги на bpm 135): нет щелчка и NaN при наложении голосов.
- Экстремальные жесты (x, y, z на границах, pinch ±1, NaN из хоста): звук остаётся конечным, пик ≤ 1.
- `SwitchWorld` и `Seed` во время звучащей ноты: нет щелчка выше порога и нет паники в `process`.
